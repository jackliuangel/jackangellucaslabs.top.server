# 坦克大战

基于 BabylonJS 的 3D 坦克对战游戏，支持键盘和触屏双端操作。

---

## 快速开始

直接用浏览器打开 `index.html` 即可（无需本地服务器）。

---

## 游戏流程

```
大厅选人数 → 开始游戏 → 消灭所有红方坦克 → 胜利 / 阵亡 → 再玩一次
```

### 大厅设置

| 选项 | 范围 | 说明 |
|------|------|------|
| 我方坦克（含玩家） | 1–8 | 第 1 辆为玩家，其余由 AI 控制 |
| 敌方坦克 | 1–8 | 全部由 AI 控制，攻击玩家和友方 |

---

## 操作说明

### 键盘（PC）

| 按键 | 功能 |
|------|------|
| `W` | 底盘前进 |
| `S` | 底盘后退 |
| `A` | 底盘左转 |
| `D` | 底盘右转 |
| `←` `→`（方向键）| 炮塔左转 / 右转 |
| `↑` `↓`（方向键）| 射击距离 +1.2m / −1.2m |
| `Q` | 炮塔左转（同 `←`） |
| `E` | 炮塔右转（同 `→`） |
| `空格` | 发射炮弹 |

> **底盘与炮塔独立控制**：底盘转向不影响炮口朝向，炮塔角度始终相对于底盘叠加。

---

### 触屏（手机 / 平板）

界面左右各有一个虚拟摇杆（nipplejs 实现）：

| 摇杆 | 操作 | 效果 |
|------|------|------|
| **左摇杆** | 推向任意方向 | 控制底盘移动方向和速度（等同 WASD） |
| **右摇杆** | 左右推 | 炮塔旋转 |
| **右摇杆** | 上下推 | 射击距离增大 / 减小 |
| **🔥 按钮** | 点击 | 发射炮弹 |
| **▲ 远 / ▼ 近** | 长按 | 持续调整射击距离（每 120ms 步进 5m） |

## 界面说明

```
┌─────────────────────────────────────────────────┐
│  [小地图]              [比分板: ● 3 vs ● 3]      │
│                                                  │
│          3D 战场（BabylonJS 渲染）               │
│                                                  │
│  [HP 血条] [装填环]  [准星]        [射程 60m]    │
│                              [▲远] [▼近]         │
│  (左摇杆)                          (右摇杆)      │
│                        [🔥]                     │
└─────────────────────────────────────────────────┘
```

### 左上角 — 小地图（圆形）

- **以玩家为中心，玩家朝向始终朝上（▲ 指示）**
- 绿色箭头：玩家坦克，始终在中央，箭头尖端朝上表示车头方向
- 红色扇形：炮塔指向的射击视野（FOV ≈ 70°），随炮塔转动
- 浅绿圆点：友方 AI 坦克
- 红色圆点：进入交战范围（≤108m）的敌方坦克

### 右上角 — 比分板

- 蓝色 `●`：我方存活数量（含玩家）
- 红色 `●`：敌方存活数量

### 左下角 — HUD

| 元素 | 说明 |
|------|------|
| **HP 血条** | 绿→黄→红随血量变化；数字显示精确 HP |
| **装填环（圆环）** | 绿色表示可开炮；橙色弧线为装填进度（装填时间 2.5 秒） |
| **准星** | 四线间距反映当前散布——移动中散布增大，静止后收紧 |

### 右下角 — 射程控制

- **`60m` 显示**：当前瞄准距离，炮弹弹道仰角自动根据此距离计算
- 颜色：绿色=有效范围 / 红色=超出范围 / 橙色=即将命中敌方

### 3D 场景落点标记

炮管前方地面会显示一个**绿色环 + 黄色圆点**，实时预测炮弹落点：

| 标记颜色 | 含义 |
|----------|------|
| 绿色静止 | 正常范围内 |
| 红色 | 超出有效交战距离 |
| 橙色脉冲闪烁 | 预测落点覆盖敌方坦克，可开炮 |

## 坦克机制

| 参数 | 数值 |
|------|------|
| 最大速度 | 6 m/s |
| 转向速率（底盘） | 0.0275 rad/帧 |
| 炮塔旋转速率 | 0.0075 rad/帧 |
| 炮弹初速 | 55 m/s |
| 最大射程 | ≈ 151 m（45° 仰角） |
| 装填时间 | 2.5 秒 |
| 爆炸半径 | 20 m |
| 单发伤害 | 30 HP |
| 坦克总血量 | 100 HP |

- 坦克在行进中**散布增大**，停止后散布恢复
- 低血量（< 30%）持续冒黑烟
- 被击中时机体变暗，血量越低颜色越深

---

## 胜负判定

| 结果 | 条件 |
|------|------|
| **胜利** | 消灭所有敌方坦克 |
| **阵亡** | 玩家坦克被击毁 |

结算界面显示累计造成伤害与击杀数，点击「再玩一次」返回大厅。

## 🎮 彩蛋：童年秘技（Konami）

在游戏中依次按下 `W W S S A D A D A B`（即 ↑↑↓↓←→←→AB），听到一声清脆的 **"ding"** 后，秘技模式**永久开启**（本局有效，无需再次输入）：

- 此后**每次底盘操作**（按 `W/A/S/D` 或推动左摇杆）都会触发瞬移：
  - 你的坦克被传送到**第一辆存活敌方坦克** 90 米半径内的随机位置（25–90m）；
  - 车头自动对准目标、炮塔持续锁定（弹道仰角按真实地形求解），**每次开火必中**；
  - 目标敌坦被冻结成「活靶子」，装填瞬间完成、散布归零；
  - 锁定期间你仍可自由操控底盘，炮塔会自动补偿瞄准；
- 目标被摧毁后自动切换到下一辆存活敌坦，全程无需重新输入秘技。

> 键盘秘技仅在 PC 上可输入；但激活后，触屏左摇杆同样能触发瞬移。
